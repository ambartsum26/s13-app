# Ассистент по участкам

Небольшое браузерное приложение для ведения городов, участков, истории выдач и базы возвещателей с хранением данных в Firebase Firestore.

## Структура

- `index.html` — базовая HTML-разметка и минимальные fallback-стили.
- `app.js` — точка входа и подключение модулей.
- `app-core.js` — Firebase, города, участки, возвещатели, выдача/сдача и история.
- `app-ui.js` — общий внешний вид и компоновка приложения.
- `app-cards.js` — оформление и поведение карточек участков.
- `app-popups.js` — модальные окна, Esc, закрытие по фону и блокировка прокрутки.
- `s13-export.js` — экспорт регистра S-13.

## Принцип изменений

Данные Firestore изменяются только через действия пользователя в `app-core.js`. UI-модули не удаляют и не перезаписывают данные базы.

Перед крупными рефакторингами сохраняются резервные ветки GitHub, чтобы рабочее состояние можно было восстановить.

## Вход владельца

`app-auth.js` инициализирует Firebase и показывает форму входа по почте и паролю. Приложение читает базу только после подтверждения UID владельца. Сеанс ограничен текущей вкладкой. При выходе подписки отключаются, открытые формы закрываются, загруженные данные удаляются из интерфейса.

`firestore.rules` ограничивает чтение и запись тем же UID. Ограничение в JavaScript не заменяет серверные правила. GitHub Pages не публикует правила Firebase автоматически: их нужно опубликовать отдельно в консоли Firestore после проверки входа владельца. Не публикуйте правила до проверки UID и рабочего входа.

Проверки без обращения к рабочей базе: `node tests/auth.test.cjs`. Они покрывают отказ без входа и чужому UID, вход владельца, выход, ошибки входа, отключение подписок и запоздавшие ответы. Реальные правила проверяются отдельно в симуляторе Firebase.

Резервные копии данных и пароли нельзя сохранять в публичном репозитории.
